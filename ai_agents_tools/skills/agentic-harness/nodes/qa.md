# QA

Run the project's tests. Do not implement features. Do not "improve" coverage unless tests fail for a reason you must report.

Discover how this repo runs tests (README, package manifest, pytest, npm test, cargo test, etc.). Run that command. Paste the command and the result into `nodes/<your-id>.md`.

Verdict: `pass` if the test run succeeds; `fail` otherwise. On fail, include failing names and the decisive log lines.
